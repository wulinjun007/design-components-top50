方法论

榜单怎么来、怎么排除、怎么复现——口径全部透明。

1 · 入选口径

  • 公开 GitHub 仓库，核心产出为 UI 组件库 / 界面模板 / 设计基建（CSS 底座、图标、动效、图表、邮件组件）。
  • 非 archived（pico.css 16.9k、shoelace 13.8k 因归档被排除）。
  • 按 Star 降序取前 50；51–60 名列入「遗珠名单」。
  • 框架类项目（如 Next.js、Vite）不入榜——它们不是设计资产。

2 · 数据采集

  • gh CLI GraphQL 批量查询（76 个候选一次往返），REST 补测修正路径。
  • 字段：stargazerCount / isArchived / licenseInfo.spdxId / pushedAt。
  • 快照时间：2026-10-06/07；许可以仓库 SPDX 标注为准，NOASSERTION 者核对项目声明并标注。

3 · 排除与勘误记录

4 · 风险标注（站内可见原则）

  • animate.css（#7，82.9k）：Hippocratic 2.1 道德许可，非标准 OSI 开源，商用过法务；本站只借鉴「动效词表」思想。
  • scrollreveal（#40，22.5k）：仓库无 LICENSE 文件＝默认版权保留；本站不使用。
  • GSAP（#27，28.8k）：Webflow 所有、标准许可需注册；借鉴时间轴思想不引代码。
  • foundation/yeti（#25，29.8k）：已更名低维护，保留为历史参考位。

5 · 复现命令

# 批量实测（GraphQL 单次往返，别名数=仓库数）
gh api graphql -f query='{ r0: repository(owner:"twbs",name:"bootstrap"){stargazerCount isArchived licenseInfo{spdxId}} ... }'
# 单仓补测
gh api repos/twbs/bootstrap --jq '.stargazers_count'

6 · 局限性

  • Star ≠ 质量：人气受生态位、先发、营销影响；榜单用于「看清地图」，选型仍需结合场景。
  • 快照制：数字为 2026-10-06/07 时点值，不实时刷新（换取零依赖、可离线）。
  • 「能力拆解」为编辑判断，欢迎按仓库文档复核。
